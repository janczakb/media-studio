Choose **Photos** in the library sidebar. Browse all visual files, images, videos, or favorites. Switch between year, month, and day groupings. The timeline uses each file's Studio creation date in UTC, falling back to its last update when the creation date is unavailable.

## Adjust the grid

Choose square or original-aspect thumbnails and use the zoom controls to change grid density. Adjusting the grid does not change the file. Open a thumbnail to inspect the asset in the [file viewer](/file-previews).

For example, to review references collected this week, choose **Days** and **Images**. Use **Starred** to narrow that timeline to your favorites. Use [All files filters](/filters-and-sorting) if you need extension, uploader or size criteria.
