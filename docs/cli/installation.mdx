---
title: "Install and verify the CLI"
description: "Install the packaged CLI or use a checkout with Node.js 22 and later."
---

Use Node.js 22 or later on macOS, Linux or Windows. Download the package from the [CLI landing page](/cli). Run the installation command in the directory containing the downloaded archive.

```bash
node --version
npm install --global ./useflex-media-studio-cli-0.1.0.tgz
flex-studio --help
```

The archive filename matches the current development package, version 0.1.0. Use the actual filename if your distribution provides another version. A separate published npm distribution must be available before using a registry installation.

## Run from a checkout

From the Media Studio repository root, install the local package or execute its entry point directly.

```bash
npm install --global ./packages/cli
flex-studio --help
node packages/cli/cli.mjs --help
```

## Make the first local plan

```bash
flex-studio import ./photos --dry-run --json
```

This reads local files without creating folders or uploading bytes. It needs neither an endpoint nor a token. Without a pattern or manifest, every nonempty regular file is planned independently, so keep your manifest and logs outside the directory being imported.

When the plan is correct, [connect a managed MCP credential](/cli/authentication) and choose the destination workspace.
