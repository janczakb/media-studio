---
title: "Search and paginate results"
description: "Search a workspace and pass the opaque continuation cursor to the next request."
---

Use a managed credential with `studio_search_files` and access to the workspace. The command forwards your query to Studio's MCP search tool.

```bash
flex-studio search 'oak chair' \
  --workspace 01J9GQ4ZPS9Z91FMY3JC5M8HJX --json
```

Without `--json`, each matching file is printed as an ID and name. If another page exists, the output includes a next cursor. JSON output contains the server response as a single JSON object, including `items` and any continuation metadata.

## Request the next page

```bash
flex-studio search 'oak chair' \
  --workspace 01J9GQ4ZPS9Z91FMY3JC5M8HJX \
  --cursor 'CURSOR_FROM_PREVIOUS_RESPONSE' --json
```

Keep the workspace and query the same and pass the cursor unchanged. Each command fetches one page. In automation, stop when the response has no next cursor. A saved cursor is scoped to the server's search context and can become invalid after relevant changes.

For empty results, compare the same query in Studio, confirm the workspace and file permissions, and inspect the [search index](/search). Use the [MCP tool reference](/mcp-tools) when building a client needing additional tool arguments.
