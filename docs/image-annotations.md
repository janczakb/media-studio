---
title: Annotate images
description: Review images with drawing tools, versioned overlays and comments.
---

Open an editable image and choose **Edit** in the preview. Use the drawing toolbar to mark a region with a shape, add a freehand line, or label a detail with text. Select a mark to adjust its properties or remove it. Choose **Save** to persist the marks.

## Review without changing the original

The preview stores a drawing against a specific image version. Hide the overlay to see the unmarked image. The original image and its download retain their original pixels. For a discussion attached to the asset, use [file comments](/comments). For a replacement file created by an editor integration, see [Originals and edited versions](/media-versions).

Try circling a detail in an image with write access. Save, reload the preview, and toggle annotations off and on. Preview the file as a viewer to check the distinction between reviewing a saved overlay and editing it.

## Handle version changes

A save uses the entry revision and the active image version. If the file was updated while the editor was open, reopen the current version before editing again. Reviewers with an embedded instance can use the [Preview SDK](/image-preview-sdk) to tailor available controls.
