# Support

FLEX Media Studio is a self-hosted media library for Laravel with optional Filament and FLEX Fields integrations.

- **Documentation:** https://studio.bjanczak.com/
- **Setup and configuration:** https://studio.bjanczak.com/installation
- **Filament components:** https://studio.bjanczak.com/filament
- **AI and search:** https://studio.bjanczak.com/ai
- **Troubleshooting:** use the documentation for the affected integration, then open a reproducible bug report.
- **Feature requests:** use the feature request template and describe the media workflow you want to improve.
- **Security:** follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

Include the installed build/version, relevant dependencies, minimal configuration and steps to reproduce. Remove credentials, private media and personal data from examples.

This repository currently contains the product presentation and repository tooling. Package source and installable distributions are not published here. The repository's automated checks cover its published content, assets, archive rules and maintenance workflows; they do not certify the private package implementation.
