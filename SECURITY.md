# Security policy

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/janczakb/media-studio/security/advisories/new). Do not open a public issue containing an exploit, token, private media URL or personal data.

Include the affected version/build, integration, prerequisites, impact and minimal reproduction. For access-control issues, identify the expected workspace/tenant boundary without including real users' data.

The maintainer will review the report and coordinate next steps through the private advisory. No response-time or bounty commitment is implied.

## Scope

Reports about Media Studio, its published repository tooling and documented integrations are welcome. Vulnerabilities in a third-party service should also be reported to that provider through its own security process.

Report the affected package version and include a minimal reproduction against the published source. Never include production credentials or private customer data.
